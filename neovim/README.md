# Neovim configuration moved to NitroVim

The Neovim configuration and NothingOS colorscheme are maintained in
[NitroVim](https://github.com/lxz-401/NitroVim).

See the [NothingOS theme guide](https://github.com/lxz-401/NitroVim/blob/main/docs/nothingos-theme.md)
for theme selection, palette customization and transparency controls.

This desktop repository links to NitroVim rather than keeping a second copy of
its theme runtime or configuration patches.
